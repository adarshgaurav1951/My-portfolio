# My-portfolio
## Adarsh Gaurav — AI & Data Science Portfolio

A modern, high-performance, and interactive portfolio web application showcasing end-to-end Machine Learning pipelines, Multimodal Deep Learning, and RAG architectures.

---

## 🚀 Key Highlights & Interactive Features

- **Multimodal Heart Disease Prediction Lab**: Real-time ECG waveform canvas coupled with interactive clinical biomarker sliders (Age, Blood Pressure, Cholesterol, ST-Depression) demonstrating feature fusion.
- **RAG Video Teaching Assistant Lab**: Interactive step-by-step pipeline demonstration using OpenAI Whisper large-v2, BGE-M3 dense embeddings, and locally served Llama 3.2 via Ollama.
- **Interactive Developer CLI**: Floating zsh-style terminal shell supporting commands (`help`, `skills`, `projects`, `demos`, `resume`, `contact`, `sudo`).
- **Curated Skills Matrix**: Categorized and filterable technical toolkit with proficiency meters.
- **Direct Resume Integration**: 1-click download and in-browser preview of official resume PDF.

---

## 🛠️ Technology Stack

- **Frontend**: React 19, Vite 6, Modern Vanilla CSS3 (Custom Glassmorphism, CSS Grid & Flexbox)
- **Icons**: Lucide React + Custom SVG Brand Icons
- **Fonts**: Google Fonts (*Plus Jakarta Sans* and *JetBrains Mono*)
- **Animations**: HTML5 Canvas API (Neural Background & Real-Time ECG Waveform)

---

## 📦 Getting Started Locally

1. **Clone the repository:**
   ```bash
   git clone https://github.com/adarshgaurav1951/My-portfolio.git
   cd My-portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the local development server:**
   ```bash
   npm run dev
   ```

4. **Build for production:**
   ```bash
   npm run build
   ```
